# Vacation Challenge

Protótipo de um aplicativo de mensagens para iOS desenvolvido em SwiftUI durante o Vacation Challenge. O projeto teve como principal objetivo aplicar as recomendações das Human Interface Guidelines (HIG) da Apple para criar uma interface consistente, intuitiva e alinhada aos padrões da plataforma.

## Sobre o projeto

O aplicativo simula um sistema de mensagens instantâneas, contemplando as principais telas de navegação, conversa individual, conversa em grupo e contatos. Durante o desenvolvimento, foram priorizadas boas práticas de usabilidade, acessibilidade e consistência visual seguindo as Human Interface Guidelines (HIG).

## Funcionalidades

- Listagem de conversas
- Conversa individual
- Conversa em grupo
- Lista de contatos
- Pesquisa de contatos
- Indicador de usuário digitando
- Status de leitura das mensagens
- Menu de contexto para mensagens
- Suporte ao Modo Claro e Modo Escuro
- Interface adaptada ao teclado
